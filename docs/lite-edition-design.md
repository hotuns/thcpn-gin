# IES Watch 精简私有化版（Lite Edition）设计文档

> **状态**：待评审
> **适用范围**：单仓库主线（`dev`）演进，面向客户自有服务器（具备外网访问能力）的单机私有化部署。

---

## 1. 背景与设计目标

仓库历史上存在两版相关尝试：
- `VITE_SIMPLIFIED_ENABLED`（已回退）：仅在用户前端散落 `if` 判断隐藏页面，维护成本高，未涉及后台与后端精简；
- `codex/onprem-lite` 分支：较早期的单机部署探索，仅覆盖 LoRaWAN V2 数据源，且和主线渐行渐远。

本次重设计的目标是建立一套**与主线同源、开关集中、前后端协同**的精简私有化版（以下简称 **Lite 版**）：

1. **客户视角，去厂商化**：部署在客户自有服务器，移除多租户 SaaS 运营、商业计费以及厂商交付客户信息（所属单位/联系人/电话/出厂认领贴标等）。
2. **精简控制台体验**：用户端登录后默认直达「一张图」，仅保留核心运维与数据查看闭环；同时保留轻量的「项目 / 样地」分组与「设备配置」能力。
3. **全设备/全数据源兼容**：支持与正式版一致的全部 5 类设备体系（THCPN 标准站、THCPN 组网、LoRaWAN V2 网关/节点、碳汇站、视频站）与全部数据源适配器。
4. **最小单机依赖**：去除 OSS、短信/邮件验证码、算子容器（`processor`）等云端或重型外部依赖；客户服务器有外网，天地图底图可直接使用。
5. **不拉长期分叉分支**：全部能力在主线通过后端运行配置 `DEPLOYMENT_PROFILE=onprem-lite` 与前端构建开关 `VITE_LITE_MODE=true` 集中控制。

## 2. 总体架构与开关机制

```
┌────────────────────────────────────────────────────────────────────┐
│  单机 Docker Compose（5 容器：web / api / worker / postgres / redis） │
├──────────────────────────────┬─────────────────────────────────────┤
│  用户前端 (@thcpn/platform)    │  后台管理 (@thcpn/admin)             │
│  构建开关: VITE_LITE_MODE=true │  构建开关: VITE_LITE_MODE=true       │
│  集中配置: src/app/edition.ts  │  集中配置: src/edition.ts            │
├──────────────────────────────┴─────────────────────────────────────┤
│  Go 后端 (api / worker / adminctl)                                  │
│  运行开关: DEPLOYMENT_PROFILE=onprem-lite                           │
│  本地存储: ./data/objects | 固定单默认工作区 | 全数据源适配器          │
└────────────────────────────────────────────────────────────────────┘
```

### 2.1 集中式裁剪原则
- **禁止**在几十个业务组件中零散读取 `import.meta.env.VITE_LITE_MODE`。
- 用户端与后台管理各自维护单一配置入口 `edition.ts`，向外暴露声明式能力集合（`edition.homePath`、`edition.navKeys`、`edition.allowedRoutes`、`edition.deviceTabs`、`edition.showVendorDossier` 等）。
- 路由层统一拦截未授权路径并重定向至默认首页（用户端 `/atlas`，后台 `/admin`），避免通过收藏夹或深链接进入已裁剪页面。

## 3. 用户前端（`@thcpn/platform`）精简设计

### 3.1 登录与认证入口
- **保留**：账号（邮箱/手机号/用户名）+ 密码登录、MFA（如管理员或用户主动启用）、首次登录强制改密。
- **隐藏**：手机短信验证码登录、自助注册入口、短信忘记密码、演示账号模式切换、登录营销轮播图。

### 3.2 导航与路由裁剪

默认落地页：**`/atlas`（一张图）**。

| 导航/模块 | Lite 版处置 | 说明 |
| :--- | :--- | :--- |
| **一张图（`/atlas`）** | **核心保留（默认首页）** | 站点/设备状态、实时指标、历史趋势、现场图片总览 |
| **设备（`/devices`）** | **核心保留** | 全部 5 类设备列表、项目/样地筛选与设备详情 |
| **设备地图（`/device-map`）** | **保留** | 基于客户天地图 Token 展示全部设备空间分布 |
| **数据导出（`/exports`）** | **保留** | 单设备/批量/碳汇数据导出与下载，不展示商业额度 |
| **项目与样地（`/settings?tab=resources`）** | **轻量保留** | 仅保留「项目 / 样地」分组维护；隐藏组织资料、外部授权、邀请、复杂权限矩阵与审计 |
| **账号设置（`/account`）** | **轻量保留** | 保留个人资料、修改密码、语言与深浅主题偏好；隐藏邮箱验证码绑定 |
| 概览（`/dashboard`） | 隐藏（重定向至 `/atlas`） | 由一张图承担首页入口 |
| 数据对比（`/data-compare`） | 隐藏 | — |
| 数据集（`/datasets`） | 隐藏 | — |
| 数据处理（`/processing`） | 隐藏 | 无 `processor` 容器 |
| 预警管理（`/alerts`） | 隐藏 | — |
| 通知中心（`/notifications`） | 隐藏 | 顶栏隐藏铃铛入口 |
| 订阅计费（`/subscription`） | 隐藏 | — |
| 多组织管理（`/workspaces`） | 隐藏 | 侧栏隐藏工作区切换器 |
| 新手导览 & 数字样地演示 | 隐藏 | 顶栏隐藏帮助导览按钮 |

> 移动端底部导航同步精简为 4 项：**一张图、设备、地图、更多（导出/项目样地/账号）**。

### 3.3 设备详情页（`DeviceCenterDetailPage`）裁剪
- **保留 Tab**：
  - `overview`（概览）
  - `data` / `video`（时序曲线、图片、视频）
  - `profile`（基础资料、安装位置与安装照片）
  - `config`（**保留设备配置**：采样策略、采集/传感器配置，隐藏其中的“计算指标”面板或仅保留采样与传感器配置）
- **隐藏 Tab 与入口**：
  - `sharing`（外部分享、公开访问二维码）
  - `activity`（复杂审计活动流，按需精简）
  - 顶部“创建预警”快捷按钮、设备列表“认领设备（`/devices/claim`）”入口。

## 4. 后台管理（`@thcpn/admin`）去厂商化设计

后台面向**客户单位自己的系统管理员**，彻底剔除厂商交付与 SaaS 商业运营功能。

### 4.1 菜单裁剪对照（19 项 → 保留 13 项）

| 分组 | 保留菜单 | 隐藏/移除菜单 |
| :--- | :--- | :--- |
| **总览** | `系统概览`（移除多工作区/计费风险卡片，聚焦设备/数据源/巡检健康状态） | — |
| **设备运维** | `设备列表`、`设备巡检`、`设备地图`、`数据导出`、`固件发布` | — |
| **采集配置** | `数据源管理`（全源支持）、`传感器模板`、`传感器模板 V2` | `系统元数据`、`数据处理方案` |
| **账号管理** | `用户管理`（内部账号开号/改密/停用） | `工作区管理`、`演示账号`、`全平台公告`、`订阅计费` |
| **系统** | `平台日志`、`管理员账号`、`系统设置`（仅保留基础查询/导出限额与站点地址，移除登录营销图设置） | — |

> 顶栏的快速跳转 `Select（⌘K）` 与 `Breadcrumb` 自动复用 `edition.ts` 的菜单白名单。

### 4.2 设备详情与档案的“去厂商化”明细

1. **安装档案（`AdminDeviceDossier`）**：
   - **移除（厂商交付客户信息）**：
     - `所属单位`（`organization`）
     - `联系人`（`contact_name`）
     - `联系电话`（`contact_phone`）
     - `运维标签`（`ops_tags`）
     - `从其他设备沿用交付信息和地址` 快捷复制按钮（或仅保留地址沿用）
   - **保留（客户自有资产信息）**：
     - `安装日期`、`安装人`、`安装地址`、`安装说明`、`安装坐标（WGS84）`、`安装照片`、`正式观测起始时间`。
     - 卡片标题由「安装与交付档案」简化为「安装档案」。
2. **资产与归属区（`AdminDevicesPage`）**：
   - **移除**：`ClaimCredentialSection`（出厂认领码生成与二维码标签打印）。
   - **简化归属**：
     - 单工作区模式下，新建或从数据源同步的设备**自动归属默认工作区**；
     - 详情页移除「解除工作区分配」危险操作，将「调整分配」简化为调整**所属项目 / 样地**；
     - 设备列表筛选栏隐藏「分配状态（已分配/未分配）」筛选项。
3. **完整保留的专业运维能力**：
   - 全 5 类设备创建、数据源同步、传感器/采集配置、LoRaWAN V2 节点发现与批量导入、碳汇配置、视频绑定、固件发布、设备巡检、数据与日志查看、误建设备删除。

## 5. 后端精简边界与初始化（`DEPLOYMENT_PROFILE=onprem-lite`）

### 5.1 后端行为调整
1. **固定单工作区（`DEPLOYMENT_WORKSPACE_ID`）**：
   - 后台新建/同步设备时，若未显式传入 `workspace_id`，自动关联至默认工作区；
   - 管理员在「用户管理」创建普通用户时，自动将其加入默认工作区（赋予标准成员或管理员角色），免去再去工作区管理手动拉人的步骤。
2. **关闭 SaaS/云端特性**：
   - `billing_enabled` 强制为 `false`（跳过下载额度与基础版时间窗限制）；
   - 关闭短信/邮件验证码发送、公开自助注册、演示账号、公开设备免登访问（`/api/v1/public/devices/*`）、数据处理任务接口（`/api/v1/*/processing*`）；
   - 对象存储默认使用本地文件系统（`OBJECT_STORAGE_PROVIDER=local`，挂载 `./data/objects`），不依赖阿里云 OSS。
3. **保留全部数据源能力**：
   - 保留 `thcpn_legacy_mysql`、`lorawan_v2`、`carbon`、`ezviz` 等全部已注册数据源适配器；
   - 不再像旧 `codex/onprem-lite` 那样强制依赖 `gateways.txt` 文件才能启动。

### 5.2 一键初始化命令（`adminctl onprem-init`）
首次部署时由 `bootstrap` 任务执行（幂等，重复运行安全）：
1. 创建/确认默认工作区（记录固定 UUID）；
2. 创建/确认初始系统管理员账号（来自 `site.env`）；
3. 创建/确认初始普通用户账号（可选，自动加入默认工作区）；
4. 若默认工作区尚无一张图配置，创建一份默认「一张图」记录，确保首次登录 `/atlas` 即可开箱使用。

## 6. 单机部署与运维方案（`scripts/onprem/`）

### 6.1 容器拓扑（5 容器，无 `processor`）
| 服务 | 镜像/来源 | 职责 |
| :--- | :--- | :--- |
| `postgres` | `postgres:16-alpine` | 平台业务库（持久化 `./data/postgres`） |
| `redis` | `redis:7-alpine` | 会话黑名单、缓存、Asynq 任务队列（`./data/redis`） |
| `api` | Go `api` 二进制 | HTTP API（`DEPLOYMENT_PROFILE=onprem-lite`），挂载 `./data/objects`、`./data/logs` |
| `worker` | Go `worker` 二进制 | 异步数据导出、设备巡检、固件任务 |
| `web` | Caddy（或单 Nginx） | 静态托管 Lite 版 `/` 与 `/admin/`，反代 `/api`、`/healthz`、`/readyz` |

> 迁移与初始化通过 Compose `tools` profile（`migrate`、`bootstrap`）一次性执行，不常驻内存。

### 6.2 最小配置清单（`site.env`）
客户现场部署仅需填写：
- `SITE_BIND_IP` / `SITE_WEB_PORT`（或域名与 HTTPS 配置）
- `POSTGRES_PASSWORD`、`JWT_SECRET`（`install.sh` 自动随机生成）
- `INIT_ADMIN_EMAIL` / `INIT_ADMIN_PASSWORD`
- `VITE_TIANDITU_TOKEN`（用于地图底图，构建阶段注入或打包时指定）
