# 原位生态云用户前端改版

用户原话：“我要重新设计这个用户前端系统，现在的不够美观”；“你来定，这是一个用来展示物联网设备采集的数据和图片的网站”。

目的：让设备采集的数据与图片成为核心；面向观察人员、科研人员和设备管理者。
输出：三套自包含 HTML 高保真原型，统一 1440×900 桌面和 375×812 移动端；包含总览、设备列表/详情、采集影像、数据分析的可点击入口。
内容：原有组织、设备、数据集与导出业务。启用状态不可说成在线，真实数值未知时不用模拟数值冒充。
假设：保留现有品牌；首轮只比较设计，不修改产品业务源码。首页弱化审计，以设备、图片和趋势为主。参考森林航拍不是站点采集照片，明确标识；图表、位置示意明确标识。
五问：叙事是快速了解现场；读者桌面近距离操作；A清透/B自然/C沉静；首屏以图像和设备为核心、趋势次之；母题来自观测设备连接时序数据与现场图片。
