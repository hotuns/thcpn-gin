2. 现实参照 / ArcGIS Dashboards：官网与地图元素文档核实，浏览超时，未亲眼看到，不以此宣称视觉复刻。借地图联动设备的工作方式；主角是标注为示意的空间图；地图大区+右设备与图片+下方趋势；胆量花在空间入口。form来自设备布设的空间性。推荐B。
3. 现实参照 / Linear Projects：https://linear.app/docs/projects，refs/linear.jpg 已亲眼查看。借其暗色中性层级、1px分割、约220px侧栏与18/14/12字体层级；主角是图片与曲线；内容/图片并排+趋势/设备并排+底资源条；胆量是深色持久在线视野。form来自设备持续观测。推荐C。
