# 平台收费模式（第一版）

本文记录 THCPN 平台第一版商业方案。方案以设备销售为主要业务入口，平台基础能力永久免费，工作区通过年度专业版取得高级数据能力。

文中的专业版年费和流量扩展包价格均为初步定价，后续可以根据真实云成本、客户接受度和续费情况调整。

## 商业原则

- 收费权益归属于工作区，不归属于个人用户；
- 用户只是工作区成员、管理员或付款人；
- 不以设备数量作为软件收费和降级限制；
- 基础版保证已购设备持续接入、采集和基础查看；
- 专业版按功能收费，不拆分多个在线档位或标准功能附加包；
- 企业定制能力继续通过线下合同报价；
- 第一版不接在线支付，全部通过线下订单或合同收款后由系统管理员授权。

## 套餐结构

### 基础版

基础版永久免费，不限制已购设备数量，包含：

- 设备认领、接入、采集和基础管理；
- 查看最近 90 天遥测数据；
- 查看压缩图片预览；
- 单设备、最近 7 天范围内的手动数据导出；
- 手动数据导出次数不限。

基础版不包含：

- 完整历史数据在线查询；
- 跨设备、长时间范围、批量或自动化导出；
- 标准数据处理；
- 开放 API；
- 自动任务和高级告警；
- 原始分辨率图片下载。

基础版的短时间、小体积数据导出不单独计费，也不要求购买下载流量包。

### 专业版

专业版暂定每个工作区每年人民币 2,000 元，包含全部标准高级功能：

- 平台保留的完整历史数据在线查询；
- 跨设备、长时间范围、批量和自动化数据导出；
- 平台标准数据处理算法和处理流程；
- 开放 API；
- 自动任务、定时报表和高级告警；
- 原始分辨率图片下载；
- 每月 100 GB 下载流量额度。

专业版不限制标准数据处理的任务次数。平台可以通过并发数、单次数据范围和运行资源限制保护系统，但不向客户销售计算积分或任务点数。

### 企业服务

以下能力通过线下合同单独报价，不再拆成多个专业版档位：

- 私有部署；
- 定制算法；
- 定制第三方接口；
- 超出标准范围的大规模离线计算；
- 大额下载流量；
- 特殊服务响应和保障。

## 专业版授权

### 线下购买与后台授权

第一版不接入微信、支付宝、银行卡或其他在线支付。标准流程为：

1. 客户通过设备采购订单或服务合同购买专业版；
2. 公司按现有财务流程收款和开票；
3. 系统管理员在后台为目标工作区授予专业版；
4. 授权记录保存来源、合同或订单号、金额、起止日期、原因和操作管理员；
5. 工作区成员共享专业版权益。

### 设备订单赠送专业版

- 一份设备采购订单或合同最多赠送一年工作区专业版；
- 赠送年限不按订单内设备数量叠加；
- 专业版权益属于工作区，不分别记录为某台设备的服务期；
- 工作区已有有效专业版时，新订单赠送的一年从现有到期日顺延；
- 工作区专业版已经到期时，新授权从合同约定的生效日开始；
- 每条授权保留其订单或合同来源，工作区对外只显示最终有效期。

示例：

```text
订单 A：2026-01-01 购买设备，授权至 2026-12-31
订单 B：2027-01-01 再次购买设备，授权顺延至 2027-12-31
```

## 下载流量

### 月度额度

每个专业版工作区每月包含 100 GB 下载流量：

- 每个自然月重置；
- 未使用额度不结转；
- 原图、数据文件、批量导出包和开放 API 文件下载合并计算；
- 不按图片、数据、文件数量或 API 调用次数分别计费；
- 普通页面数据查询和压缩图片预览不计入下载额度；
- 优先消耗套餐月度额度，额度耗尽后再消耗流量扩展包。

### 超额处理

- 使用达到 80% 和 95% 时通知工作区管理员；
- 达到 100% 后暂停专业文件下载；
- 不自动产生超额费用或月底补账；
- 设备采集、页面查看、图片预览、数据处理和普通 API 数据查询继续可用；
- 购买流量扩展包或进入下一自然月后恢复下载。

### 流量扩展包

- 暂定人民币 100 元/100 GB；
- 通过线下方式购买，由系统管理员增加至工作区；
- 扩展包余额长期有效；
- 专业版到期时余额保留但暂停使用；
- 工作区重新取得专业版后恢复使用。

## 图片访问

图片查看和原图交付分开处理：

- 图片列表和详情使用压缩预览图；
- 用户可以持续查看图片预览；
- 原图只能通过受控下载、批量导出或开放 API 文件接口交付；
- 原图交付消耗工作区下载流量额度；
- 页面不得把原图当作普通预览资源加载。

OSS 成本优化的后期实施方案见 [OSS 成本优化方案](./oss-cost-optimization.md)。

## 开放 API

- 开放 API 是专业版内含能力，不作为独立套餐销售；
- API 凭证归属于工作区，只能访问该工作区授权的数据；
- 普通 JSON 数据响应不单独计费；
- 通过 API 下载文件时计入工作区下载流量；
- 企业服务可以提供更高资源限制、定制接口和服务保障。

## 到期与降级

专业版到期前 30 天、7 天和 1 天通知工作区管理员。到期日直接恢复基础版，不额外赠送缓冲期：

- 设备继续接入、采集和查看，不删除、不停用；
- 图片预览继续可用；
- 在线历史窗口恢复为最近 90 天，较早数据继续保留；
- 停止创建新的专业数据处理、批量导出和自动任务；
- 开放 API 凭证暂停使用；
- 原图和其他专业文件下载暂停；
- 基础版单设备最近 7 天手动导出继续可用；
- 正在运行的任务允许执行完成；
- 已经生成的导出文件继续按原 72 小时有效期下载；
- 流量扩展包余额保留，重新取得专业版后恢复。

## 第一版后台能力

后续实现收费功能时，后台至少需要提供：

- 查看工作区当前套餐、授权来源和最终到期时间；
- 按合同或订单授予、顺延和纠正专业版期限；
- 记录合同号、订单号、金额、授权原因和操作管理员；
- 查看月度下载额度、使用量和扩展包余额；
- 增加流量扩展包；
- 查看即将到期、已到期和流量即将耗尽的工作区；
- 保留所有授权、调整和流量包操作记录。

## 暂定商业参数

| 参数 | 第一版暂定值 |
|---|---:|
| 专业版年费 | ¥2,000/工作区/年 |
| 专业版月度下载额度 | 100 GB |
| 流量扩展包 | ¥100/100 GB |
| 基础版在线历史窗口 | 最近 90 天 |
| 基础版单次导出范围 | 单设备最近 7 天 |
| 导出文件有效期 | 72 小时 |

这些数值是可调整的商业配置，不应写死在业务判断中。后续根据云成本、工作区真实用量、客户续费率和销售反馈重新定价。
