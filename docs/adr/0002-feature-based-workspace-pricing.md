# 按工作区和功能收费，而不是按设备数量收费

THCPN 以设备销售为主要业务入口，因此基础版不以设备数量限制已购设备的接入、采集和基础查看。商业权益归属于工作区：工作区按年取得统一专业版，获得完整历史、专业导出、标准数据处理、开放 API、自动任务和下载流量额度；私有部署、定制算法和特殊保障进入企业服务。选择功能分层而不是设备分档，可以避免专业版到期时停用设备，也避免组网站 Node、碳汇 Node 等不同设备结构产生难以解释的计费口径。

专业版第一版通过线下订单或合同收款后由系统管理员授予，不接在线支付。一份设备采购订单最多赠送一年工作区专业版，不按订单内设备数量叠加；下载产生的可变成本通过专业版月度下载额度和流量扩展包控制。
