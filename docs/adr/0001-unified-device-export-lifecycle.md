# 统一设备导出生命周期并保留体系专属交互

标准站、组网站和碳汇站共享数据导出页、异步任务生命周期、ZIP 基础契约、七十二小时文件有效期和下载入口，但各自拥有独立的导出创建界面。统一一个条件分支表单会弱化三种设备体系不同的目标选择模型，而完全分离任务系统又会造成状态、权限、文件结构和下载体验不一致；因此统一交付契约，不统一领域交互。

## Consequences

- 标准站使用批量设备清单，组网站使用单站节点树，碳汇站使用单站的 Node × 地块组合矩阵。
- 设备页仅深链并预填对应创建界面，不直接创建导出任务。
- 新设备导出统一生成 ZIP；碳汇 ZIP 可包含通量和原始采样。
- 所有设备查询默认使用当前时间向前七天，不额外查询最新数据时间。
- 导出包使用 `generation-report.csv` 描述生成结果，不推断源数据质量。
