# 统一设备导出生命周期并保留体系专属交互

标准站、组网站和碳汇站共享数据导出页、异步任务生命周期、ZIP 基础契约、七十二小时文件有效期和下载入口，但各自拥有独立的导出创建界面。统一一个条件分支表单会弱化三种设备体系不同的目标选择模型，而完全分离任务系统又会造成状态、权限、文件结构和下载体验不一致；因此统一交付契约，不统一领域交互。

## Consequences

- 标准站使用批量设备清单，组网站使用单站节点树，碳汇站使用单站的 Node × 地块组合矩阵。
- 设备页仅深链并预填对应创建界面，不直接创建导出任务。
- 新设备导出统一生成 ZIP；碳汇 ZIP 可包含通量和原始采样。
- 所有设备查询默认使用当前时间向前七天，不额外查询最新数据时间。
- 导出包使用 `generation-report.csv` 描述生成结果，不推断源数据质量。

- 标准站与设备批量导出的遥测和图片按最长 30 天的时间窗口顺序读取；每段独立保证完整性和分页，合并时去重相邻窗口的闭区间边界记录，保留起止端点。该分段属于离线导出编排，不放宽在线查询或来源分表数量限制。
- 若存在读取或图片下载失败，且没有成功打包任何遥测记录或图片，任务必须标记 failed，不上传仅含说明和报告的 ZIP。部分内容成功时保留成功内容与生成报告；查询正常但确实无记录不等同于读取失败。

- 网关级 Excel/CSV 的“全部指标”导出包含网关直属诊断指标及所有有效节点指标，使用与节点查询一致的目标目录；列出节点名称并保留数据流、设备身份。同一数据流不重复导出。网关及节点没有可导出指标时明确报错，不生成仅有表头的成功任务。

- 网关 Excel/CSV 使用节点与精确采集时间组成行的宽表：固定列为节点名称、节点 ID、节点序号和北京时间，各指标独立成列（名称、代码及单位）。不同节点不合并，不同时间不插值，缺失值留空；独立设备原有格式不变。

- 通用遥测 Excel/CSV（含数据集 ZIP 内遥测文件）同样使用宽表，按设备身份与精确采集时间分行，指标列包含名称、代码和单位；有质量标记的指标保留独立质量列。标准站 ZIP 与碳汇文件已有宽表结构，继续保持；图片索引、清单、元数据与生成报告不是时序指标表，不作指标透视。
