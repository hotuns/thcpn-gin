# 后台设备运维工作台

系统管理员使用独立管理员会话，直接管理所有设备及设备数据，不依赖工作区成员关系、设备分享、用户套餐或用户登录态。普通用户端继续使用原有授权和套餐规则。查询仍执行技术上的时间、分页和记录数校验，大量数据使用异步导出。

后台提供安装资料、观测分类、人工安装坐标、安装照片、节点名称和位置、原始指标表、图片分页预览与下载、碳汇通量/原始采样周期、监控站预览、采集计划及下载任务。源配置、固件、认领铭牌、设备分配和日志沿用既有来源实现。界面使用 Ant Design；摄像机画面按需加载既有萤石 SDK。

后台导出复用现有 Worker 打包、临时文件、对象存储上传、进度和失联处理机制。`export_jobs.requested_by_admin` 记录管理员，用户发起者和工作区为空；普通用户任务保留原有用户及工作区字段。数据库约束保证两种来源互斥。Worker 根据持久化的管理员字段决定是否需要用户授权，客户端不能通过导出参数切换身份。管理员可下载用户和后台任务，普通用户接口不能访问后台任务。后台下载不消耗用户套餐流量预算。

安装坐标属于人工记录的静态资产资料，存储在 `device_profiles`，优先于源设备位置和站点位置。清空人工坐标恢复原有位置来源。这里不缓存实时设备位置，也不修改数据源的上报值。LoRa V2 节点位置仍在节点资料中独立管理，不继承网关人工坐标。普通资料修改和数据源同步不能覆盖人工安装坐标。

设备查询通过现有 adapter，下载使用受控 token 或临时签名地址；配置写入沿用源端版本校验和平台同步流程。操作记录保留真实管理员身份。源端接受配置不等于硬件已经生效，后台提示运维核对后续上报。
