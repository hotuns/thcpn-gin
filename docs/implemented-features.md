# THCPN 当前功能实现清单

本文档是当前代码实现的功能索引，便于开发、联调和验收。HTTP 字段以 `docs/openapi.yaml` 为准，数据库表以 `migrations/000001_init.up.sql` 为准。

## 1. 身份与入口

平台有两套相互隔离的身份体系：普通平台用户和系统管理员。普通用户通过 `/login`、`/register` 进入 Workspace 控制台；系统管理员通过 `/admin/login` 进入系统后台。两套会话、导航和权限上下文彼此独立。

已实现：

- 密码登录、短信验证码登录、密码注册、邮箱验证和 TOTP MFA。
- access token / refresh token 会话、主动注销、会话撤销和密码修改流程。
- 普通用户注册时创建个人工作区和 Owner 关系。
- 系统管理员独立登录、用户管理、临时密码、账号停用/解锁、MFA 重置和会话撤销。
- 用户平台和系统后台互相跳转，未授权访问受保护页面会进入对应登录入口。

## 2. Workspace 与权限

普通用户以 Workspace 为数据边界。Workspace 下包含项目、站点、成员、设备使用关系、数据集、导出任务和审计记录。

- 支持个人工作区和组织工作区；创建者是 Owner。
- 创建者不能离开自己创建的工作区，只能删除工作区。
- 支持项目、站点的创建、编辑、归档和层级管理。
- 支持成员、角色模板、显式权限、资源 scope、AccessGrant、Invitation 和审计。
- scope 支持 Workspace、Project、Site、Device、DataStream 和 Dataset。
- 外部分享、售后授权、邀请均可撤销；售后授权必须有有效期。
- Owner、最后一个有效 Owner、内部管理权限等高风险约束由后端保护。

## 3. 设备源库与系统设备

系统管理员在 `/admin/sources` 管理受控数据源。平台只保存数据源元信息和外部设备映射，不保存源库 DSN 正文。

### 3.1 同步方式

- 输入标准站外部 ID，可同步单个标准站。
- 输入网关外部 ID，可同步网关及其节点拓扑。
- 支持全量同步设备。
- 根据源库 `devices.device_type` 识别设备：`type < 10` 为标准站，`type = 10` 为网关，`type > 10` 为节点。
- 从源库 `cameras` 表同步相机及视频能力。
- 同步会更新已有平台设备的稳定信息、数据流目录、外部映射和网关/节点关系。
- 设备经纬度、海拔、实时电压、信号、在线状态等源库属性在查询时读取，不在平台重复缓存。

### 3.2 归属与拓扑

- 同步设备先进入系统设备资产，不在同步阶段强制分配 Workspace。
- 管理员后续可以把网关分配给 Workspace、Project 和 Site。
- 节点不单独分配 Workspace；节点权限通过当前网关的有效分配继承。
- 管理员可以调整网关与节点拓扑，拓扑变化后权限随新的父网关生效。
- 系统设备支持批量选择、批量状态/环境属性操作、分页、搜索和类型筛选。

## 4. 用户平台设备功能

主要入口是 `/devices` 和 `/devices/:deviceId`。

- 设备列表支持项目、站点、类型、状态、拓扑展开和分页展示。
- 网关可展开查看继承权限的节点；快捷切换设备会根据设备类型自动修正目标标签。
- 普通设备详情包含概览、数据、资料、配置、分享和操作记录。
- 相机详情只显示实时视频、资料和操作记录，不显示不适用的配置、分享和概览功能。
- 设备资料集中维护设备描述、项目、站点、观测分类、业务元数据和资料图片。
- 设备配置支持设备维护模板、可视化编辑和 JSON 编辑；协议参数、指标、端口编号和扩展字段可维护。
- 设备运行属性和实时位置通过源库读取；用户编辑的数据属于平台业务资料。
- 支持校准、采样配置、固件升级等已开放的设备操作，并记录操作状态和审计。

## 5. 认领、公开访问与相机

### 5.1 设备认领

- 管理员为可认领设备生成永久设备铭牌二维码和手工认领码。
- 永久二维码长期有效，可重复使用；设备解绑后仍可再次认领。
- 用户扫码或输入设备序列号/认领码进入 `/claim`。
- 扫码的当前登录用户就是本次认领操作者。
- 认领时选择目标 Workspace，可选 Project 和 Site；后端保证幂等。
- 网关认领后，节点继续通过网关继承权限。

### 5.2 公开设备页面

- 设备可开启固定公开地址 `/public/devices/:publicSlug`。
- 固定地址和二维码不会因关闭、重新开启或修改访问密码而改变。
- 可选访问密码；密码验证后在当前浏览器保持有限期会话。
- 公开页面只读，展示最近遥测和图片，不暴露后台配置、源库连接或管理操作。

### 5.3 相机

- 相机从源库 `cameras` 表同步。
- 支持供应商、序列号、通道、清晰度、加密和验证码引用等绑定信息。
- 具备视频能力的设备可按需创建实时视频会话，离开页面或切换设备时释放播放器。

## 6. 设备数据与分析

### 6.1 单设备数据

设备详情的“数据”页用于查看单个设备的遥测、图片和视频数据。

- 快捷时间范围支持 6 小时、3 天、7 天；也支持自定义时间范围。
- 遥测图表支持分指标查看或同图对比、隐藏/恢复指标、独立 Y 轴和数据明细表。
- Hover 显示真实采样时间、原始值、单位和质量，不使用时间百分比代替时间。
- 查询范围最多 366 天，点数和请求条数受后端限制；服务端错误信息和 request ID 会反馈到页面。
- 图片按数据流分页加载；相机使用实时视频会话。

### 6.2 数据对比

`/data-compare` 用于选择任意设备、数据要素和时间范围进行联合分析。

- 支持添加多个设备/要素/时间段组合。
- 原始值模式保留原始单位，按单位使用独立 Y 轴。
- Min-Max 模式把每条序列按当前查询范围缩放到 0–1，用于比较变化形态。
- Z-score 模式展示相对均值的标准差倍数，用于比较偏离程度。
- 横轴可选择实际采样时间，或把不同时间范围映射为 0–100% 的进度对齐。
- Hover 始终显示具体采样时间；对比条件可保存为数据集来源。

### 6.3 数据集与导出

- 数据集保存查询定义、设备/数据流来源、项目、说明和时间范围，不复制原始遥测。
- 数据集详情展示来源设备、数据要素、时间范围和预览结果。
- 支持遥测 CSV、Excel、媒体 ZIP 和数据集 ZIP 等异步导出任务。
- 导出任务有 pending、running、success、failed、expired 等状态，并提供过期控制和错误原因。

### 6.4 计算数据流

- 用户可为设备配置一个计算数据流和公式。
- 公式可引用同一设备的原始遥测数据流和数字型设备元数据。
- 计算结果不持久化，查询时按同一设备、同一时间戳读取原始数据并计算。
- 元数据和公式修改会影响后续对历史时间范围的重新计算；修改操作写入审计日志。

## 7. 分类、地图与实时信息

- `/device-map` 展示当前 Workspace 设备的精确位置分布。
- `/admin/device-map` 展示系统范围设备地图、已定位/未定位/未分类统计和设备列表。
- 地图位置优先使用源库实时 `lat`、`lon`、`alt`；站点业务位置可作为回退位置。
- 设备分类使用可维护词典，不把草原、农作物、沙尘监测、树木胸径、植物物候、草原修复等业务概念硬编码成设备列。
- 后台支持按生态类型、观测对象、用途、管理方式和部署方式筛选，并支持批量设置设备分类。

## 8. 系统后台

系统后台使用 Ant Design 管理组件，表格采用紧凑布局，并提供独立夜间模式。

- `/admin`：API 健康、24 小时错误/警告、设备/数据源/用户/工作区规模、待处理事项、设备类型结构和常用操作。
- `/admin/sources`：数据源配置、环境变量 DSN 引用、单设备同步、网关同步、相机同步和全量同步。
- `/admin/devices`：系统设备搜索、类型/状态/生命周期筛选、分页、多选批量操作、拓扑、生命周期、能力、配置、相机绑定、认领二维码和 Workspace 分配。
- `/admin/sensors`：平台传感器模板 CRUD、分页、状态筛选、从源库导入，以及协议参数和指标的可视化/JSON 双模式编辑。
- `/admin/device-map`：系统设备地图、分类筛选、子节点显示和批量分类。
- `/admin/logs`：平台日志按时间、级别、服务、状态、操作者、请求 ID 和关键词检索，支持详情、原始文件、导出和索引重建。
- `/admin/workspaces`：工作区治理、成员、项目、站点、直接授权、邀请和审计详情。
- `/admin/users`：普通用户账号状态、锁定、MFA、会话、活动和临时密码管理。
- `/admin/metadata`：设备能力字典、系统角色和显示元数据维护。
- `/admin/settings`：健康检查、就绪检查和权限目录。

## 9. 数据边界与不变量

- 平台 PostgreSQL 保存业务主数据、权限、设备稳定身份、拓扑、分配、数据流定义、映射、模板、元数据、计算公式、数据集和审计。
- THCPN 源库保存设备实时位置、运行属性、原始遥测、图片和源库设备属性；平台按需读取。
- 计算结果、实时位置、电压、信号和在线状态不在平台业务库建立冗余缓存。
- 删除平台设备不会删除 THCPN 源库原始数据。
- 删除工作区会清理其成员、项目、站点、授权、数据集和导出任务。
- 高风险操作必须带原因并写入审计；错误响应保留后端消息和 request ID。
