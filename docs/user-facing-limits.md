# 用户端限制与错误提示

以下数值是默认值。系统管理员可在 **系统设置 → 业务参数** 按组调整查询与展示、上传与输入、一张图与预警、导出、账号验证、公开访问与 API、套餐参数。

系统设置保存在平台 PostgreSQL 中；首次使用以部署配置和代码默认值初始化，保存后由数据库配置覆盖对应默认值。保存需要确认修改前后数值并填写原因，配置、修改历史与系统审计在同一事务中提交。可查看最近 50 次变更，并将本组启动默认值填入表单后再确认保存。

API 为每个请求读取一次配置快照；Worker 在领取导出任务前读取快照，任务执行中不改变配置。用户端在加载前获取公开配置，并每 30 秒刷新。配置影响新请求；已有导出文件、验证码、登录锁定的到期时间不回写。

**启用套餐限制** 开关也在后台维护：关闭会取消套餐功能门槛和下载额度检查，不取消查询、上传、长度等业务参数。开关默认来自部署的 `billing.enabled`，保存后由后台配置控制，无需重启。

## 查询与下载

| 场景 | 当前限制 | 超限后的提示或处理 |
| --- | --- | --- |
| 普通指标查询、图片查询、数据集预览 | 单次请求跨度默认最多 366 天 | 说明实际允许天数、本次跨度及缩短范围的办法 |
| 指标数据 | 单次请求每个指标默认最多 5,000 条 | 明确是单次请求限制；用户端完整曲线自动拆分请求，不把 5,000 条当作整张图的总上限 |
| 完整曲线拆分 | 时间片小于等于 2 秒后仍未完整返回则停止 | 说明每请求 5,000 条、数据源未完整返回，并建议导出或联系管理员核对完整性标记；不静默截断或改成抽样 |
| 图片分页 | 每页默认最多 100 张 | 说明每页上限，建议翻页 |
| 数据集查询 | 必须位于数据集保存的起止时间内 | 显示允许的北京时间起止范围，与单次跨度限制分别判断 |
| 数据比较 | 最多 8 个对比项 | 添加入口显示“已达到 8 项上限” |
| 异步遥测导出 | 每个指标单任务最多 10,000,000 条 | 失败说明指标条数上限及缩短范围、分批导出的办法 |
| 用户导出时间范围 | 含图片默认最多 31 天；不含图片默认最多 365 天 | 混合导出按图片上限；如套餐限制更短，仍按套餐执行。系统管理员可在系统设置的导出任务中调整。 |
| 导出分段 | 后台按 30 天窗口读取，默认初始请求 100,000 条，不完整时增加请求条数 | 30 天和 100,000 条是内部读取参数，不是整个导出任务的时间／条数上限 |
| 导出有效期 | 默认 72 小时 | 过期后提示重新创建任务；具体过期时间以任务返回值为准 |

结束时间必须晚于开始时间。范围错误会用“开始时间／结束时间”描述，不直接显示 `start_time`、`end_time`、`max_history_days` 等内部字段名。

## 内容长度与上传

长度按 Unicode 字符统计，密码另按 UTF-8 字节统计。

| 内容 | 上限 |
| --- | --- |
| 姓名 | 100 字符 |
| 组织名称 | 120 字符 |
| 节点名称 | 50 字符；不能含换行或控制字符 |
| 预警名称 | 120 字符 |
| 预警持续时间 | 0–2,592,000 秒（30 天） |
| API 密钥名称 | 100 字符 |
| 数据处理任务名称 | 128 字符（与数据库已有字段长度一致） |
| 一张图名称／描述 | 120／300 字符 |
| 组织一张图手动选择设备 | 最多 50 台 |
| 一张图趋势范围 | 最多 720 小时（30 天） |
| 用户自定义标签 | 最多 30 个，每个最多 50 字符 |
| 设备安装照片 | 每设备最多 12 张，每张最多 10 MB；仅 JPEG、PNG、WebP |
| 用户端设备描述 | 默认最多 500 字符，用户端与服务端使用系统配置；管理员安装维护备注仍走后台资料流程 |
| 新密码／重置密码 | 默认 8–72 字节，需同时含字母和数字；实际最小／最大值由后端密码策略决定，最大值同时受 bcrypt 72 字节限制 |
| 公开访问密码 | 默认 8–72 字节，读取系统密码长度配置 |

安装照片数量校验包含已有照片和本次上传数量。密码错误说明英文字母、数字、英文符号各占 1 字节，中文通常各占 3 字节，避免把字节上限误认为中文字符数。登录输入框保留兼容既有凭据的行为。

## 套餐、验证码与访问频率

- 套餐限制仅在计费策略启用时生效，不能把默认基础版窗口当成所有组织的限制。基础版历史查询默认仅最近 90 天、导出默认仅最近 7 天；错误显示实际配置值，导出结束时间不能超出当前时间（后端容许 5 分钟时钟偏差）。专业版、停用计费时不套用基础版窗口。批量、数据集和部分文件导出需要专业版。
- 下载额度受组织套餐、月度使用量和流量包影响。额度不足时显示本次需要多少 MB、当前剩余多少 MB（含流量包），不只提示“权限不足”。默认专业版月度额度 100 GB，以实际组织配置为准。
- 短信／邮箱验证码默认同一手机号／邮箱每天最多申请 10 次，两次至少间隔 60 秒；错误返回当前配置值。这里统计的是申请次数，并不承诺每次申请都能成功投递。
- 公开设备密码：同一设备、同一出口 IP 在 15 分钟内最多尝试 5 次。
- 公开设备接口按设备、出口 IP、接口类别分别限频：遥测每分钟 60 次、图片 240 次、解锁 60 次、其他 120 次。
- 每个 API 密钥每分钟最多调用 600 次（当前进程内限频）。
- 账号锁定继续使用已有错误详情中的剩余冷却时间，不把认证服务故障显示为次数超限。

## 可配置与技术约束

- 名称、标签、照片、图表条数、查询跨度、导出条数、文件有效期、分段窗口、磁盘预留、验证码频率、公开访问频率与基础套餐参数均可按后台字段给出的范围调整。
- 密码最大 72 字节仍受 bcrypt 限制；LoRaWAN V2 1–254 序号仍受协议限制，不把技术约束伪装成可解除的套餐限制。
- Worker 并发、数据库连接、服务地址和存储密钥等部署参数不在用户业务配置中，继续通过部署环境维护。
- 不提高字段上限时不会改变原有行为；提高节点名、预警名、API 密钥名、处理任务名与一张图名称上限时，数据库字段已同步支持，不会再次被旧的长度约束拒绝。

## 错误契约

API 沿用原有状态码与错误封装，`error.details` 增加可公开的限制信息：

- `LIMIT_EXCEEDED`：`field`、`maximum`、`actual`、`unit`。套餐窗口只携带适用上限。
- `DATASET_TIME_WINDOW`：`start_at`、`end_at`，以明确时区的时间戳传递，用户端格式化为北京时间。
- `PASSWORD_LENGTH`：`minimum`、`maximum`、`unit: bytes`。
- `VERIFICATION_LIMIT`：`channel`、`period`、`maximum`。
- `DOWNLOAD_ALLOWANCE`：`required_bytes`、`remaining_bytes`。

用户端统一通过 `formatApiError` 显示具体上限及可执行的调整办法，保留请求编号。查询参数和输入超限保持 HTTP 400，套餐限制 HTTP 403，频率限制 HTTP 429。未开放的内部错误仍使用通用服务错误，不透出数据库错误。

维护限制时同时更新服务端校验、公开错误详情和本清单。不要只修改提示里的数字，也不要为没有产品限制的字段新增任意上限。
