# 一张图 / DataV 组件重构

Reference: https://github.com/DataV-Team/DataV-React

Uses the actual adapted production components and CSS. This is an isolated,
unauthenticated component review, not an API mock or a substitute for testing
the authenticated Atlas screens. The controls switch between the existing three
compositions; the clock is live. Device and map placeholders are clearly marked.

Run `node designs/atlas-datav/build-preview.mjs`, then serve this directory over
HTTP. `index.html` is the standalone generated review artifact.
